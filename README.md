# vdx-bench

This repository runs benchmark jobs for a private project on GitHub Actions. It holds only the workflow (`.github/workflows/bench.yml`). The code it runs comes from a private package at run time, and the results go back to the private project, which checks them.

Pull requests, issues and outside contributions are not accepted.
